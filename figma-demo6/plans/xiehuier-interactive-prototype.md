# “歇会儿”小程序风格交互原型实施方案

## 1. 目标与已确认决策

在当前 React + Vite + Tailwind CSS v4 项目中，制作面向外卖骑手、快递员、网约车司机等群体的完整移动端交互原型。交付为预览面板中可操作的 Web 应用，不是微信原生代码，不包含管理后台。

用户已确认：
- **保留底部 Tab**：采用“歇会儿 / 倾诉记录 / 我的”三项导航，覆盖 UI 规范中的“无底部 Tab”要求。
- **纯前端演示闭环**：无后端、真实 AI、微信登录、录音、摄像头或数字人 SDK。
- **首页优先**：首次打开直接展示首页；第一次进入聊聊时，再完成“选择聊天伙伴 → 完善基本信息”两步初始化。

其余冲突的优先级：用户明确选择 > 参考图的视觉语言和品牌规范 > PRD 的交互与数据要求。产品统一命名“歇会儿”，不在用户界面沿用 PRD 的“情绪树洞”名称。

## 2. 已核实的项目情况

- `src/App.tsx` 是空白主组件，`src/index.css` 仅导入 Tailwind。
- 已有 React 19、Vite 8、TypeScript、Tailwind CSS v4，无现成组件库、图标库或路由依赖。
- `package.json` 提供 `build`、`dev`、`preview`、`format`，没有测试或 typecheck 脚本。
- 使用现有受托管的开发服务器与热更新，不另启服务。
- 已阅读 PRD V6.3、UI 设计风格规范，并查看完整首页参考图。

## 3. 视觉实施标准

- 首页以 `#1A54A8 → #3474D1` 深蓝渐变、白色大标题“歇会儿”、标语“先停一分钟，心里别硬扛”为核心。
- 首页主视觉保留树桩、安全头盔，以及“超时委屈 / 路上奔波 / 客户差评 / 想找人说说话”场景气泡。使用自制 SVG 插画表达参考图的结构，不把整张截图当页面背景，也不引入无关照片。
- 唯一主行动色 `#FF8A29`，次要功能使用 `#4096FF`，呼吸模块使用 `#4ECDC4`；错误和紧急提示可以使用语义红，不增加第二个竞争性的橙色主按钮。
- 白色圆角卡片、轻阴影、宽松行距；正文深灰，次级页面使用 `#F7F9FC`。系统中文无衬线字体，无需外部字体下载。
- 以约 390px 宽手机视口设计，手机全宽；桌面居中展示最大约 480px 的应用画布，外侧为中性背景。兼顾 320px 窄屏及底部安全区，不出现横向滚动。
- 左右安全边距约 16px，触控区不小于 44px；卡片圆角约 12–20px。正文通常 16px，辅助说明不低于 13px。
- 使用一组本地线性 SVG 图标，不使用 emoji。按钮仅有轻微按压反馈，页面短淡入；呼吸动画尊重减少动态效果设置。
- 默认为参考图的明亮蓝色主题；“我的”提供可持久保存的夜间模式，采用藏蓝而非纯黑背景。
- 不伪造可操作的微信胶囊或手机状态栏。保留小程序式标题栏与返回体验。

## 4. 页面和交互规格

### 4.1 首页（默认 Tab）

从上到下：
1. 品牌标题与标语。
2. 树桩头盔插画和场景气泡，气泡点击后携带对应话题进入聊聊流程。
3. 白色主卡片：“今天遇到什么事？”＋橙色“我想聊聊”按钮。
4. 三栏白色功能卡片：“语音说说 / 呼吸一下 / 同行故事”。
5. 简短提示：“先停稳车，再安心聊。”以及前端演示说明入口。
6. 固定三项底部导航，正文为其预留空间。

“我想聊聊”进入普通聊天；“语音说说”进入语音演示模式。未初始化时先进入两步流程，保留原入口和场景，完成后自动继续。呼吸和故事无需初始化。

### 4.2 两步初始化

**第一步：选择聊天伙伴**
- 提供三位固定伙伴，例如“老周（踏实倾听）/ 小林（轻松陪聊）/ 阿岚（温和鼓励）”，使用统一风格的简约插画头像。
- 默认选中老周，可切换；显示“第 1 步，共 2 步”及“下一步”。
- 明示“聊天伙伴为演示形象，未连接真人或数字人服务”，不伪装在线真人。

**第二步：认识一下**
- 年龄：整数输入，范围 1–120；性别：男 / 女 / 不愿透露；职业：外卖骑手 / 快递员 / 网约车司机 / 其他新就业形态。
- 年龄与职业必须填写，性别默认“不愿透露”；校验失败在字段旁显示短提示。
- 说明“仅用于本机原型演示，请勿填写真实敏感信息”，点击“开始聊聊”保存后继续目标页面。
- 返回上一步不丢输入；关闭流程返回来源页面，不标记为已完成。已保存的选择下次恢复。
- 不做虚假的微信授权步骤；原型自动使用本地演示身份。

### 4.3 聊聊页

- 次级全屏页面隐藏底部 Tab，顶部返回、伙伴名字和“演示伙伴”状态。
- 伙伴形象区显示简短状态（听你说 / 正在回复 / 陪你缓缓），不模拟真实口型或语音播放。
- 初始欢迎语及可点选的话题；主体为清晰的消息气泡，自动滚动至最新消息。
- 底部提供文本输入、发送、语音演示、图片演示入口。文本去除首尾空白后才能发送，最多 500 字；等待回复时禁止重复提交。
- 模拟回复延迟约 600–1000ms，显示“正在回复”。普通自由输入走固定共情模板，不声称具有语义理解或真实风险识别能力。
- 语音演示：显示可开始、停止、取消的录音样式面板及计时，完成后生成一条明确标注“模拟转写”的预设语音消息；不调用麦克风。
- 图片演示：选择内置场景图片/插画卡片，可删除再发；不打开相册，不做表情分析。支持文本或语音演示与图片组合。
- 可结束本次聊天，回到记录列表；无消息的空会话不保存。发送第一条消息时创建会话，后续消息即时更新本地记录。
- 历史会话可继续聊天；新建聊天使用新的会话 ID。返回不丢失已经发送的内容，取消未发送的模拟录音或附件不生成记录。
- 聊天页明确显示“回复为预设演示，不提供诊断或紧急救援”。

### 4.4 分级关怀演示

为复现 PRD 的四级前端表现，在聊聊页菜单中提供独立“体验关怀场景”入口，选择四个预设场景。通过场景 ID 决定演示结果，不把关键词匹配包装成 AI 判断。

| 场景 | 演示输出 | 前端表现 |
| --- | --- | --- |
| 日常跑单疲惫 | level 4 / normal | 普通共情回复 |
| 投诉带来的委屈 | level 3 / normal | 共情回复＋呼吸资源卡 |
| 连续失眠、难以支撑 | level 2 / hotline | 可关闭的温和热线弹窗 |
| 需要立即获得帮助 | level 1 / emergency | 置顶紧急支持弹窗，提供 12356、110、120 |

- 一级弹窗不允许点遮罩或 Escape 立即关闭；阅读 5 秒后才显示“我已了解，继续聊聊”。倒计时期间不妨碍使用求助按钮。
- 二级弹窗可以立即关闭，提供 12356 和 PRD 中的“宁师傅”025-96889910，注明地方渠道可能受地区与服务时间限制。
- 热线按钮二次确认后通过 `tel:` 交给设备处理，不自动拨号；桌面同时支持复制号码并提供失败提示。
- 真实求助文案清晰克制：“如果你或身边的人正处于危险中，请立即拨打 110 或 120，或联系身边可信的人。”
- 风险等级仅为演示内部状态，不给用户贴诊断标签；不声称已通知后台、人工跟进或完成危机识别。
- 多模态矛盾与趋势升级若需展示，通过同一菜单中的两条固定示例展示说明与最终关怀卡，不实现真实识别、记忆推理。

### 4.5 呼吸一下

- 首页功能卡和聊天资源卡均可进入。
- 提醒停稳车辆、在安全位置使用；采用“吸气 4 秒 → 呼气 6 秒”，共 6 轮、约 1 分钟，无憋气环节。
- 显示呼吸圆环、阶段文字、剩余时间和轮数。可开始、暂停、继续、重新开始；离开时清理计时器。
- 完成后展示“缓过来一点了吗？”及“回去聊聊 / 回首页”，按来源恢复导航。
- 减少动态效果模式下保留文字与数字引导，不依赖缩放动画。

### 4.6 同行故事

- 列表包含 3–4 篇本地短故事，围绕超时、差评、跑单疲惫、同伴互助。
- 点击进入详情，显示短段落和“我也想说说”入口；进入聊天时带入对应话题。
- 显示“演示故事，非真实投稿”，无用户发布、评论或联网内容。

### 4.7 倾诉记录 Tab

- 按最近更新时间排列本机实际产生的会话，显示日期、话题和最后一条消息摘要。
- 首次无记录时展示友好空态与“去聊聊”，不混入伪造个人历史。
- 点击进入历史对话，可继续；支持单条删除及“一键清除”，均二次确认。
- 清空后同步删除本原型的会话和本地演示上下文，不删除伙伴、资料和主题偏好。若正在查看被删除会话则退出详情。
- 说明“仅清除此浏览器的演示记录”，不得声称清除了服务器、Mem0 或真实预警记录。

### 4.8 我的 Tab

- 显示当前伙伴、职业与初始化状态，未完成时使用访客样式。
- 提供更换伙伴、编辑基本信息、夜间模式、帮助热线、隐私与演示说明。
- 资料编辑复用初始化字段与校验，不强制已初始化用户重新走两步流程。
- 更换伙伴应用于之后的回复；历史消息保留原伙伴标识。
- 隐私说明明确：不接入微信；不采集真实音视频；数据仅存在当前浏览器 localStorage，不加密，不适合保存敏感信息；清理浏览器数据会丢失。

## 5. 技术设计

### 文件划分

- `src/App.tsx`：应用外壳、页面状态与全局弹窗组合。
- `src/index.css`：保留 Tailwind 导入，添加颜色 token、系统字体、明暗主题、安全区与呼吸动效。
- `src/components/`：标题栏、底部导航、按钮、卡片、弹窗、图标、品牌插画、伙伴头像。
- `src/pages/`：首页、初始化、聊天、记录、我的、呼吸、故事列表与详情。
- `src/lib/types.ts`：领域类型。
- `src/lib/storage.ts`：带版本的 localStorage 读写、校验与降级。
- `src/lib/demo-service.ts`：异步模拟回复、预设关怀场景、稳定的 ID 与时间处理。
- `src/data/`：伙伴、故事、热线及演示文案。

不新增 UI 框架、路由库或状态管理依赖。使用 React Context + reducer 管理共享资料和会话；页面局部交互留在组件内。用具备明确参数的页面联合类型与页面栈处理应用内返回，避免大量互斥布尔值。三个 Tab 切换回各自根页；次级页使用标题栏返回；不承诺深链接。

### 数据与服务边界

- `Profile`：age、gender、occupation。
- `DigitalHuman`：id、name、avatar、description。
- `Conversation`：id、title、digitalHumanId、createdAt、updatedAt、messages。
- `Message`：id、role、content、inputTypes、demoMediaId、digitalHumanId、createdAt，以及可选 riskLevel / intervention。
- `Intervention`：type 为 normal / hotline / emergency，及资源列表。
- `AppState`：schemaVersion、profile、selectedDigitalHumanId、conversations、theme、初始化完成状态。
- 初始化完成状态根据有效资料和伙伴选择推导，不依赖容易失配的独立标志。
- 统一通过 `demoService.sendMessage()` 返回模拟的 replyText、digitalHumanAction、riskLevel、intervention；与 PRD 的响应字段保持概念兼容，但此次不实现 HTTP、JWT、文件上传或后台预警。
- 持久化键采用带版本的命名空间，例如 `xiehuier.demo.v1`；只存 JSON 数据，不存真实媒体或凭据。

### 异常与生命周期

- 损坏或不支持版本的存储恢复为空白演示状态并提示，不导致白屏。
- 存储被禁用或写满时保留本次内存交互，提示“本次内容暂时无法保存，刷新后可能丢失”。
- 异步回复绑定会话 ID，切换页面不串会话；删除会话后返回的异步结果不重新创建已删除记录。
- 模拟失败状态提供“重试”，重试不重复插入用户消息。通过演示菜单触发失败，不随机制造失败。
- 计时器在退出和卸载时清理；紧急弹窗展示优先于其他浮层。
- 弹窗具备语义、焦点约束和关闭后焦点恢复；常规弹窗支持 Escape。紧急场景按前述规则例外。

## 6. 实施顺序

1. 实施前调用适用的设计系统技能，复核现有约束；建立主题、页面外壳、基础组件与本地 SVG 品牌资产。
2. 优先完成高保真的首页及底部导航，确保参考图核心层级成立。
3. 实现数据模型、持久化、两步初始化与资料修改。
4. 实现聊天、文本/模拟语音/模拟图片、异步回复和记录闭环。
5. 完成四级关怀卡、热线确认及失败重试演示。
6. 补齐呼吸、故事、我的、主题切换、空态与隐私说明。
7. 完成移动适配、可访问性和全流程验证。

## 7. 验证与验收

这是跨多页面的完整实现，可运行项目规定的 `pnpm build` 做最终构建验证；使用项目 `pnpm format` 格式化本次新增与修改文件，不新增无依据的检查命令。不开启第二个开发服务器。若有可用浏览器检查能力，使用既有预览做下列交互验证；没有时如实注明未执行的运行时检查。

验收清单：
- 首开首页，与参考图的蓝色、标题、树桩头盔、场景气泡、双卡片布局一致；底部额外保留用户指定的三项 Tab。
- 首次聊聊触发两步初始化，取消、返回、完成、刷新后的行为正确；故事和呼吸不受初始化阻挡。
- 可发送文本、模拟语音、模拟图片及组合输入；回复等待、重试、会话切换不串消息。
- 四个预设场景分别展示正确关怀 UI；一级延迟关闭、二级可关闭、三级资源可打开；拨号必须确认。
- 历史记录刷新后存在，可继续、单删、清空；清空不删除个人偏好。
- 呼吸流程可暂停、继续、重启、完成；离开后无遗留计时。
- 故事列表和详情可返回，故事可带话题进入聊天。
- 我的可修改资料、切换伙伴和夜间主题，刷新保留。
- 320px、390px、桌面宽度下无横向溢出、按钮被遮挡或底部内容被导航覆盖。
- 键盘聚焦、弹窗、输入校验及减少动态效果设置可用。
- 全过程不请求录音、摄像头、相册、微信权限，不发起 AI 或后台请求，不虚构安全能力或隐私承诺。

## 8. 不在本次范围

微信原生小程序代码与发布、微信真实登录、后端 API、EmoLLM、Mem0、ASR、emotion2vec+、Py-Feat、魔珐星云 SDK、真实录音上传与 TTS、人工危机转介、管理后台、生产级安全和合规认证。上述能力未来应在独立工程接入与安全评估后实现，本原型仅验证视觉与交互。
